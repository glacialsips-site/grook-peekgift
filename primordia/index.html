PRIMORDIA

how this works

Every particle belongs to a species (a color). Between any two species there is a single signed number — an attraction. That number, times a distance falloff, is the entire physics:

force(a,b) = matrix[a][b] · falloff(distance)

Run that rule across thousands of particles on the GPU every frame and life emerges: membranes, chases, pulsing cells, crystals, worms. Nothing is scripted — you only ever tune the rules, never the behavior. Edit the attraction matrix by dragging its cells (cyan attracts, magenta repels).

Genesis lets the universe run itself: it watches the world's structure and motion, gently mutates a thriving world, and triggers a rebirth when one goes static or blows apart — an endless self-curating screensaver. The Discovered worlds were found by an evolutionary search scoring random rule-sets for "alive and structured."
